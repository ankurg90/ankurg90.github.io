# In Memory of Prof. A. K. Gupta

A tribute site for Prof. Ashok Kumar Gupta (Daddu), Department of Chemical Engineering, IIT Delhi. 10 March 2026.

Live at: **https://ankurg90.github.io/Prof-AKG-Tribute/**

## Files

```
Prof-AKG-Tribute/
├── index.html          the page
├── styles.css          typography and layout
├── .nojekyll           tell GitHub Pages not to run Jekyll
├── README.md
└── assets/
    ├── og-thumbnail.jpg     1200x630 social-share image
    ├── photos/              ~14 photographs
    ├── audio/flute-tabla.mp3   background music (Indian classical, royalty-free)
    └── video/               two short video clips
```

## Preview locally

```bash
python3 -m http.server 8000
```

## Deployment

The site lives inside the `ankurg90/ankurg90.github.io` repository as the subfolder `Prof-AKG-Tribute/`, served at `https://ankurg90.github.io/Prof-AKG-Tribute/`.

To update: edit, then commit and push from the `ankurg90.github.io` checkout. GitHub Pages will rebuild within a minute or two.
